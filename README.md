# Igor Kulikov — Personal Portfolio

Static, responsive personal portfolio website. Built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use PhpStorm's built-in preview.

```bash
git init
git add .
git commit -m "Initial portfolio landing page"
```
