פרופיל

קצת עליי

אני ארכיטקט תוכנה למערכות Backend ומוביל טכני, בעל ניסיון נרחב בתכנון ובפיתוח פלטפורמות תקשורת ארגוניות בקנה מידה גדול.

תחומי ההתמחות שלי כוללים מערכות מבוזרות, Microservices המבוססים על Java ו-Spring, אורקסטרציה של תהליכים, תכנון REST APIs ומודרניזציה של מערכות לענן באמצעות Kubernetes ו-Helm.

אני משלב באופן פעיל כלי AI בתהליכי פיתוח תוכנה: לתמיכה בתכנון ארכיטקטורה ופתרונות, להאצת מימוש וניתוח קוד, ולשיפור תכנון בדיקות, יצירת בדיקות ואיתור תקלות.

לאורך הקריירה שילבתי פיתוח מעשי עם תכנון ארכיטקטורה, סקירות טכניות, חניכת מהנדסים ושיתוף פעולה עם צוותי פיתוח, מוצר וצוותים העובדים מול לקוחות.
